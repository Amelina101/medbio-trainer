ВАЖНО: ZIP нельзя загружать в GitHub как один файл.
1. Скачайте ZIP.
2. Распакуйте его на устройстве.
3. В GitHub откройте Add file → Upload files.
4. Загрузите СОДЕРЖИМОЕ распакованной папки, включая папку data.
5. Нажмите Commit changes.
6. Откройте сайт в приватной вкладке или удалите старую иконку PWA и установите заново.
