# MedBio Trainer — приложение для iPad

Это PWA-приложение. Оно устанавливается на главный экран iPad и работает почти как обычное приложение.

## Возможности

- уроки по биологии;
- карточки для повторения;
- Medical English;
- медицинская латынь;
- ссылки на 3D-анатомию;
- тесты;
- локальное сохранение прогресса;
- работа офлайн после первого открытия.

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий, например `medbio-trainer`.
2. Загрузите в корень репозитория все файлы из этой папки.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Нажмите Save.
6. Через несколько минут GitHub покажет адрес сайта.

## Установка на iPad

1. Откройте опубликованный адрес в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран Домой».
4. Нажмите «Добавить».

## Важно

Карточки и прогресс пока хранятся только на конкретном устройстве в Local Storage.
Позже можно подключить Supabase/Firebase для синхронизации между устройствами.
